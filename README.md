# sistema-reparacion-telefonos
# 📱 Sistema de Reparación de Teléfonos

## Descripción

Aplicación web para gestionar una tienda de reparación de teléfonos. Permitirá registrar clientes, dispositivos, técnicos y servicios, además de crear y dar seguimiento a las reparaciones, controlar su estado y mantener organizada la información del negocio.

## 🎯 Objetivo

Desarrollar un sistema que facilite la administración de las reparaciones de teléfonos y permita llevar un mejor control de los clientes, dispositivos y servicios realizados.

## 🛠️ Tecnologías

* C#
* ASP.NET Core
* HTML
* CSS
* JavaScript
* SQL Server
* Git y GitHub
* Visual Studio Code

## 📋 Funciones principales

* Registro de clientes.
* Registro de teléfonos.
* Registro de técnicos.
* Gestión de servicios de reparación.
* Creación de órdenes de reparación.
* Seguimiento del estado de las reparaciones.
* Consulta de información de las reparaciones.
